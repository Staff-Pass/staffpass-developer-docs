## Requisitos

Antes de llamar la API necesitas:

1. una empresa con plan Enterprise vigente;
2. `api_enabled = true`;
3. un token de integración de producción con `employees:read`;
4. la base URL `https://api.staffpass.app`.

StaffPass entrega el secreto del token una sola vez. No uses una sesión Firebase del panel, un token de TimeClock, un token de descarga ni credenciales de proveedor.

## Primera solicitud

```bash
curl --request GET \
  --url "https://api.staffpass.app/integrations/v1/employees?limit=50&active=true" \
  --header "Authorization: Bearer $STAFFPASS_INTEGRATION_TOKEN"
```

Una credencial válida devuelve una colección paginada:

```json
{
  "data": [
    {
      "id": "65f43bb2-7282-4bb7-b399-6db91a7c431f",
      "employeeCode": "EMP-001",
      "name": "Ana Pérez",
      "position": "Analista",
      "department": "Finanzas",
      "email": "ana@example.com",
      "active": true,
      "createdAt": "2026-09-01T14:30:00.000Z",
      "updatedAt": "2026-09-20T18:45:00.000Z"
    }
  ],
  "page": {
    "nextCursor": null,
    "limit": 50
  }
}
```

## Paginación y filtros

- `limit`: de 1 a 100; valor predeterminado 50.
- `cursor`: UUID devuelto en `page.nextCursor`.
- `updatedAfter`: fecha y hora ISO 8601; devuelve cambios posteriores.
- `active`: `true` o `false`.

Sigue `nextCursor` hasta que sea `null`. Los datos bancarios, biométricos, documentos y demás campos sensibles no forman parte de esta respuesta.

## Comprobación segura

Una llamada sin token devuelve `401 INTEGRATION_TOKEN_INVALID`. Esto confirma que la ruta existe, pero no concede acceso. Solicita la activación y el token a StaffPass; no intentes descubrir rutas internas.
