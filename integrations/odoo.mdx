El conector oficial de Odoo es público en
[Staff-Pass/staffpass-odoo-connector](https://github.com/Staff-Pass/staffpass-odoo-connector).
Instálalo desde la rama que corresponda exactamente a la versión principal de
tu servidor.

## Disponible en Odoo Apps

1. [Odoo 19](https://apps.odoo.com/apps/modules/19.0/staffpass_payroll_connector): publicado y gratuito.
2. [Odoo 18](https://apps.odoo.com/apps/modules/18.0/staffpass_payroll_connector): publicado y gratuito.

| Odoo | Rama | Versión del módulo | Transporte |
| --- | --- | --- | --- |
| 19.0 | `19.0` | `19.0.1.0.0` | JSON-2 autenticado |
| 18.0 | `18.0` | `18.0.1.0.0` | RPC externo autenticado |

Ambas ramas pasaron una instalación limpia contra la imagen oficial de Odoo y
pruebas transaccionales de importación, idempotencia, rechazo de conflictos,
validación contable y reversión. Esta evidencia valida el código del módulo; no
sustituye la aceptación del entorno específico de cada cliente.

## Qué hace

- recibe el asiento canónico de nómina generado por StaffPass;
- valida empresa, moneda, fecha, cuentas, centros de costo y balance;
- crea únicamente movimientos contables en borrador;
- evita duplicados con una identidad externa y un hash del contenido;
- conserva un registro de auditoría sin copiar el detalle personal de la nómina;
- genera reversiones idempotentes sin borrar el movimiento original.

El módulo no calcula nómina, no publica asientos, no guarda credenciales de
StaffPass y no abre controladores anónimos.

## Requisitos

- Odoo.sh o una instalación administrada que permita módulos Python externos;
- plan de Odoo con acceso a la API externa;
- usuario técnico exclusivo, API key y acceso solo a las empresas autorizadas;
- diario general dedicado y cuentas contables previamente configuradas;
- conexión HTTPS pública o túnel explícito para instalaciones privadas.

Odoo Online no permite instalar este tipo de módulo Python de terceros. La
instalación debe hacerse en Odoo.sh o en una instalación administrada que
permita módulos Python externos.

<Warning>
Este conector no convierte las rutas internas del panel en una API pública. La
API Enterprise general de StaffPass continúa en estado **No disponible** hasta
que existan `api_enabled`, tokens de integración y los gates documentados.
</Warning>
