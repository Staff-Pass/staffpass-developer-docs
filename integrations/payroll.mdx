## SIPE y DGI

StaffPass implementa localmente flujos revisables para registrar workbooks,
versionar mapeos, preparar previews, aprobar con separación de funciones,
generar artefactos privados y registrar evidencia manual. No realiza envíos a
los portales CSS/SIPE o DGI/e-Tax.

La validación externa sigue bloqueada hasta recibir plantillas vigentes,
procedencia, empresa piloto, reglas, calendario y aceptación de responsables.
Una captura manual o un archivo generado no equivale a presentación fiscal.

## ACH

Existen adaptadores locales separados para Banco General, Banistmo y BAC Panamá.
Solo pueden renderizar un layout explícito y versionado; no infieren columnas,
delimitadores, encoding, nombre de archivo ni checksums.

No hay layouts o muestras bancarias aprobadas. Por eso la preparación permanece
`BLOCKED_EXTERNAL_EVIDENCE` y no produce un archivo bancario específico válido
para envío.

## Regla ante ambigüedad

Una descarga, un `HTTP 200`, un timeout o una observación manual no prueban un
pago. El resultado `UNKNOWN` conserva la reserva y bloquea reintentos hasta una
conciliación explícita. StaffPass no debe marcar un comprobante como pagado sin
confirmación inequívoca.

Ninguna de estas capacidades está publicada en la API Enterprise actual.
