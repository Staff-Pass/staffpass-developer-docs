## curl

```bash
curl --request GET \
  --url "https://api.staffpass.app/integrations/v1/employees?limit=25&active=true" \
  --header "Authorization: Bearer $STAFFPASS_INTEGRATION_TOKEN"
```

Para consultar un empleado:

```bash
curl --request GET \
  --url "https://api.staffpass.app/integrations/v1/employees/$EMPLOYEE_ID" \
  --header "Authorization: Bearer $STAFFPASS_INTEGRATION_TOKEN"
```

## JavaScript

```javascript
const response = await fetch(
  "https://api.staffpass.app/integrations/v1/employees?updatedAfter=2026-09-20T00:00:00Z",
  {
    headers: {
      Authorization: `Bearer ${process.env.STAFFPASS_INTEGRATION_TOKEN}`,
    },
  },
);

if (!response.ok) {
  throw new Error(`StaffPass respondió ${response.status}`);
}

const { data, page } = await response.json();
```

## Reglas de cliente

- Guarda el token únicamente en un gestor de secretos.
- Continúa la paginación con `page.nextCursor`.
- Ante `401`, detén las llamadas y revisa activación o vigencia.
- Ante `403 INTEGRATION_SCOPE_REQUIRED`, solicita el scope; no cambies de tenant.
- Ante `429`, espera `retryAfterSeconds` antes de continuar.
- No reintentes automáticamente una solicitud fallida de forma ilimitada.

No existe una credencial pública de demostración. Los ejemplos requieren un token emitido para una empresa concreta.
