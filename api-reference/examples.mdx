## Lista de preparación de un cliente

Este es el único ejemplo ejecutable recomendado en la fase actual: validar que
el onboarding esté completo antes de escribir un cliente HTTP.

```text
[ ] Contrato Enterprise vigente
[ ] Empresa exacta confirmada
[ ] API activada explícitamente
[ ] Token de integración emitido
[ ] Base URL entregada por StaffPass
[ ] OpenAPI contiene la operación requerida
[ ] Scopes y límites documentados
[ ] Sandbox o piloto autorizado
```

Si cualquier casilla está vacía, no intentes descubrir rutas ni reutilices una
sesión Firebase.

## Manejo de resultados inciertos

```text
1. Conserva request ID e idempotency key.
2. No envíes una segunda mutación.
3. Consulta el estado con una operación publicada, si existe.
4. Si no existe, solicita conciliación a StaffPass.
5. Reanuda solo con un resultado terminal inequívoco.
```

Los ejemplos `curl`, JavaScript y Python se agregarán desde el OpenAPI aprobado,
no desde controladores internos. Esto evita ejemplos que funcionen localmente
pero omitan plan, activación, tenant o scopes.
