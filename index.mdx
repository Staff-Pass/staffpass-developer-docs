<Info>
La API Enterprise v1 está disponible en `https://api.staffpass.app`. La primera superficie pública permite consultar empleados en modo de solo lectura con un token de integración autorizado.
</Info>

**Estado público de la API: Disponible con activación Enterprise.**

El acceso requiere simultáneamente:

1. plan Enterprise vigente para la empresa;
2. `api_enabled = true`;
3. token de integración activo con el scope requerido.

El tenant se deriva del token. El cliente no puede seleccionar otra empresa mediante headers o parámetros.

Las rutas del panel administrativo usan identidad Firebase y permisos internos. No forman parte de la API Enterprise y nunca deben consumirse desde integraciones de clientes.
</Warning>

## Empieza aquí

Consulta [Primeros pasos](getting-started), solicita la [Activación Enterprise](enterprise-activation) y usa la [Referencia OpenAPI](api-reference/overview). No existe un token público compartido: cada credencial pertenece a una sola empresa.
