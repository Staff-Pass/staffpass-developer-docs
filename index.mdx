<Warning>
El conector oficial de Odoo ya está disponible. La API Enterprise general para
integraciones personalizadas todavía no está disponible: el backend no
implementa el plan Enterprise, la bandera `api_enabled`, tokens de integración
ni un guard dedicado para esos tokens. Por eso aún no se publican endpoints
operativos ni credenciales de prueba para esa API.
</Warning>

**Estado público de la API: No disponible.**

Esta guía separa tres cosas que no deben confundirse:

1. Las funciones de StaffPass implementadas y verificadas localmente.
2. La validación externa con un proveedor, portal, banco o dispositivo.
3. La futura API para clientes Enterprise.

El acceso futuro requerirá simultáneamente un contrato Enterprise vigente, la
API activada de forma explícita para la empresa y un token de integración
válido. Cumplir solo una o dos condiciones no autorizará una solicitud.

## Estado actual

| Área | Estado | Qué significa |
| --- | --- | --- |
| Portal de documentación | Publicado | El contenido se despliega desde la rama `main` en [staff-pass.mintlify.site](https://staff-pass.mintlify.site). |
| Conector oficial de Odoo | Publicado y gratuito | Disponible para [Odoo 19](https://apps.odoo.com/apps/modules/19.0/staffpass_payroll_connector) y [Odoo 18](https://apps.odoo.com/apps/modules/18.0/staffpass_payroll_connector). |
| API Enterprise | `NOT_IMPLEMENTED` | No hay endpoints externos autorizados, activación ni tokens de integración. |
| OpenAPI público | Sin operaciones | La especificación contiene `paths: {}` para evitar publicar rutas internas. |

<Note>
Las rutas del panel administrativo usan identidad Firebase y permisos internos.
No forman parte de la API Enterprise y no deben integrarse desde sistemas de
clientes.
</Note>
