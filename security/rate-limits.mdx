## API Enterprise

No existe todavía una cuota contractual para la API Enterprise. El portal no
publica números provisionales porque el gateway, la unidad de medición y el
almacenamiento compartido de contadores no están implementados.

## Backend actual

El backend tiene un límite global configurable con valor local por defecto de
120 solicitudes por 60 segundos. Sus contadores viven en memoria por proceso;
en un despliegue con varias réplicas ese número no representa una cuota global
exacta. También existen presupuestos separados para autenticación de dispositivos
y herramientas públicas.

<Warning>
Estos valores protegen el runtime actual, pero no son un SLA ni una cuota de la
API Enterprise. No diseñes capacidad de cliente alrededor de ellos.
</Warning>

## Qué debe publicarse antes de activar la API

- límite por token y, si aplica, por tenant;
- ventana y algoritmo de medición;
- encabezados de cuota y `Retry-After`;
- comportamiento con varias réplicas;
- límites de payload, paginación y concurrencia;
- política de ráfagas y solicitudes de aumento.

Hasta entonces, la única conducta válida ante `429` es detener la ráfaga y
esperar instrucciones del contrato publicado.
