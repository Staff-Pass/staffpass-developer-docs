## Límites vigentes

La API aplica una ventana persistente de 60 segundos:

| Dimensión | Límite |
| --- | --- |
| Por token | 60 solicitudes por minuto |
| Por empresa | 300 solicitudes por minuto |

Ambos límites deben permitir la solicitud. Los contadores se almacenan en base de datos, por lo que se comparten entre réplicas del servicio.

## Respuesta 429

Cuando se excede una cuota:

```json
{
  "code": "INTEGRATION_RATE_LIMIT_EXCEEDED",
  "message": "Integration rate limit exceeded",
  "retryAfterSeconds": 60
}
```

Detén la ráfaga y espera al menos `retryAfterSeconds`. Usa paginación de hasta 100 empleados por solicitud y sincronización incremental con `updatedAfter` para reducir tráfico.

<Note>
Estos son límites técnicos iniciales, no una garantía de capacidad ni un SLA. Una ampliación debe acordarse antes de diseñar cargas sostenidas por encima de ellos.
</Note>
