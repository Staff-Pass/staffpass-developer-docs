# Contribuir

1. Mantén separadas la implementación local, la validación externa y la aceptación en producción.
2. No documentes rutas internas, sesiones Firebase ni credenciales como API de clientes.
3. No agregues operaciones a OpenAPI hasta que existan los gates Enterprise y su control de acceso.
4. Usa solo ejemplos sintéticos, sin secretos ni datos personales.
5. Ejecuta `node validate.mjs` antes de abrir un pull request.
